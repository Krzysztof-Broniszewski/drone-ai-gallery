## ✨ O projekcie

Drone & AI Gallery to autorskie portfolio prezentujące projekty wykonane z wykorzystaniem generatywnej sztucznej inteligencji, lokalnych workflow w ComfyUI, montażu wideo oraz fotografii z drona. Witryna ma minimalistyczną, ciemną oprawę z akcentami złota i jest udostępniona przez GitHub Pages.

## 🎬 Wyróżniony projekt — BLACK LUXURY: BORN FROM FIRE

[**Zobacz reklamę i interaktywne case study →**](https://krzysztof-broniszewski.github.io/drone-ai-gallery/projects/volcanic-perfume/)

Autorski koncept reklamy luksusowych perfum, realizowany od projektu produktu do publikacji gotowego filmu:

1. 🎨 **Product design** — projekt flakonu na przezroczystym tle oraz ujęcia z różnych perspektyw w celu zachowania spójności produktu.
2. 🖼️ **Reference images** — obrazy Text-to-Image i sceny z produktem, w tym wykorzystanie Qwen Image 2.1 Character Sheet w ComfyUI.
3. 🎞️ **AI video** — generowanie ujęć z klatek referencyjnych, m.in. MiniMax H3 First Frame / Last Frame.
4. 🎵 **Music & sound design** — muzyka z ACE-Step 1.5 Text-to-Music oraz efekty dźwiękowe ze Stable Audio 3 Text-to-Audio.
5. 🎬 **Post-production** — montaż, synchronizacja dźwięku i przygotowanie finalnego filmu w DaVinci Resolve.
6. 🚀 **Publication** — publikacja i dokumentacja procesu w portfolio.

Generowanie materiałów AI realizowano **lokalnie**, na komputerze z procesorem **Intel Core i5-13400**, **64 GB RAM** i kartą **NVIDIA GeForce RTX 3090 (24 GB VRAM)**.

## 🖼️ Zawartość portfolio

- **AI Commercials** — reklamy generowane z wykorzystaniem AI, z opisami procesu produkcji.
- **AI Art** — galeria obrazów generowanych przez AI.
- **Drone Photography** — fotografie lotnicze.
- **Drone Videos** — filmy z drona i odnośniki do YouTube.
- **CV** — dostęp do życiorysu zawodowego.

## ⚙️ Funkcje strony

- Responsywny interfejs HTML, CSS i JavaScript.
- Wspólna nawigacja między podstronami.
- Galerie z powiększaniem zdjęć (*lightbox*).
- Interaktywny, sześciostopniowy opis procesu tworzenia reklamy.
- Materiały referencyjne, zrzuty ekranów workflow oraz przykładowe nagrania audio.
- Integracja z YouTube i publikacja na GitHub Pages.

## 🛠️ Technologie i narzędzia

**Strona:** HTML5, CSS3, JavaScript, Git, GitHub Pages.  
**Produkcja AI:** ComfyUI, Qwen Image 2.1, MiniMax H3, ACE-Step 1.5, Stable Audio 3.  
**Postprodukcja:** DaVinci Resolve.

## 🚀 Uruchomienie lokalne

Sklonuj repozytorium i uruchom `index.html` przez lokalny serwer HTTP, np. rozszerzenie **Live Server** w VS Code. Część funkcji pobierających dane lub pliki może wymagać uruchomienia przez serwer zamiast otwierania pliku protokołem `file://`.
